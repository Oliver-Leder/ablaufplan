# Ablaufplan

Interaktiver Ablaufplan für einen Hochzeitstag – eine einzelne HTML-Datei, ohne Build.

- Programmpunkte mit fester Uhrzeit oder automatisch anschließend
- Dauer in Minuten, als Endzeit oder „bis zum nächsten Punkt“
- Prüfung auf Überschneidungen, Lücken und fehlende Angaben
- Parallele Aktionen, To-dos, Kommentare, Details
- Drag & Drop, Rückgängig/Wiederholen, Export/Import als JSON, Markdown-Kopie, Druckansicht

Daten werden nur lokal im Browser (localStorage) gespeichert.
